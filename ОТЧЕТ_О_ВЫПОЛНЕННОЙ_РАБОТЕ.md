# Отчет о выполненной работе

## Выполненные задачи

### 1. Экспорт данных из базы данных в Excel
- Создан скрипт для экспорта всех данных из файла `маршрутные_карты.db` в файл `маршрутные_карты.xlsx`
- Успешно экспортировано 2500 записей из базы данных в Excel файл

### 2. Замена Kivy на Streamlit
- Создано новое веб-приложение на базе Streamlit в файле `streamlit_app.py`
- Приложение включает в себя все основные функции оригинального приложения:
  - Генерация одной маршрутной карты
  - Генерация нескольких маршрутных карт
  - Проверка дубликатов
  - Сохранение информации в Excel файл

### 3. Обновление зависимостей
- В файле `requirements.txt` заменена зависимость `kivy==2.2.1` на `streamlit==1.27.2`
- Удалены ненужные зависимости

### 4. Обновление запускающего скрипта
- В файле `запуск_приложения.py` обновлена логика запуска:
  - При наличии Streamlit запускается веб-версия приложения
  - В противном случае запускается консольная версия

### 5. Очистка проекта
- Удалены ненужные файлы:
  - `generate_form_pptx.py` (Kivy GUI версия)
  - `test_core.py` (тесты)
  - `demo_excel.py` (демонстрационный скрипт)
  - Вспомогательные скрипты для анализа (`check_db.py`, `check_excel.py`, `export_db_to_excel.py`)
  - Каталог `__pycache__`

## Как запустить приложение

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Запустить приложение:
   ```
   streamlit run streamlit_app.py
   ```

   Или использовать универсальный скрипт запуска:
   ```
   python запуск_приложения.py
   ```
