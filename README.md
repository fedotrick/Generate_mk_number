# Генератор маршрутных карт

## Описание

Проект "Генератор маршрутных карт" предназначен для автоматизированного создания маршрутных карт в формате PowerPoint с интегрированными QR-кодами. Приложение позволяет генерировать как одиночные, так и множественные маршрутные карты с автоматической нумерацией и сохранением информации в Google Sheets.

## Особенности

- Генерация маршрутных карт в формате PowerPoint (.pptx)
- Автоматическое добавление QR-кодов на карты
- Проверка дубликатов номеров бланков
- Хранение информации в Google Sheets
- Поддержка генерации как одной, так и нескольких карт одновременно
- Современный веб-интерфейс на базе Streamlit
- Автоматическое предложение следующего доступного номера маршрутной карты

## Установка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

2. Настройте Google Sheets API (см. ИНСТРУКЦИЯ_GOOGLE_SHEETS.md)

## Использование

### Веб-интерфейс (основной способ)

Дважды щелкните по файлу `запуск_streamlit.bat` или выполните в командной строке:
```
streamlit run streamlit_app.py
```

### Альтернативный запуск через командную строку

```
python streamlit_app.py
```

## Структура проекта

- `ШАБЛОН.pptx` - Шаблон PowerPoint для создания маршрутных карт
- `streamlit_app.py` - Основное приложение с веб-интерфейсом
- `google_sheets_utils.py` - Модуль для работы с Google Sheets
- `запуск_streamlit.bat` - Файл для быстрого запуска приложения
- `credentials.json` - Учетные данные для доступа к Google Sheets API (создается пользователем)
- `token.pickle` - Токены доступа к Google Sheets (создается автоматически)
- `spreadsheet_id.txt` - ID таблицы Google Sheets (создается автоматически)

## Требования

- Python 3.7+
- См. файл `requirements.txt` для полного списка зависимостей
- Аккаунт Google для работы с Google Sheets
