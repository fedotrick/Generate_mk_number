# Генератор маршрутных карт

## Описание

Проект "Генератор маршрутных карт" предназначен для автоматизированного создания маршрутных карт в формате PowerPoint с интегрированными QR-кодами. Приложение позволяет генерировать как одиночные, так и множественные маршрутные карты с автоматической нумерацией и сохранением информации в Excel файле.

## Особенности

- Генерация маршрутных карт в формате PowerPoint (.pptx)
- Автоматическое добавление QR-кодов на карты
- Проверка дубликатов номеров бланков
- Хранение информации в Excel файле
- Поддержка генерации как одной, так и нескольких карт одновременно
- Удобный веб-интерфейс на базе Streamlit

## Установка

1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Использование

### Веб-интерфейс (основной способ)

Дважды щелкните по файлу `запуск_streamlit.bat` или выполните в командной строке:
```
streamlit run streamlit_app.py
```

### Альтернативный запуск через командную строку

```
python streamlit_app.py
```

## Структура проекта

- `ШАБЛОН.pptx` - Шаблон PowerPoint для создания маршрутных карт
- `маршрутные_карты.xlsx` - Excel файл с информацией о созданных картах
- `streamlit_app.py` - Основное приложение с веб-интерфейсом
- `запуск_streamlit.bat` - Файл для быстрого запуска приложения

## Требования

- Python 3.7+
- См. файл `requirements.txt` для полного списка зависимостей
