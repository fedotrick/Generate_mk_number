# Инструкция по настройке Google Sheets для проекта "Генератор маршрутных карт"

## Подготовка Google Sheets API

1. Перейдите на [Google Cloud Console](https://console.cloud.google.com/)

2. Создайте новый проект или выберите существующий

3. Включите Google Sheets API:
   - Перейдите в "APIs & Services" → "Library"
   - Найдите "Google Sheets API"
   - Нажмите "Enable"

4. Создайте учетные данные:
   - Перейдите в "APIs & Services" → "Credentials"
   - Нажмите "Create Credentials" → "OAuth client ID"
   - Выберите "Desktop application"
   - Назовите приложение (например, "Маршрутные карты")
   - Скачайте файл с учетными данными и переименуйте его в `credentials.json`
   - Поместите файл `credentials.json` в корневую папку проекта

5. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```

## Первый запуск

При первом запуске приложения:
1. Запустите приложение:
   ```
   streamlit run streamlit_app.py
   ```
2. Откроется браузер с запросом на авторизацию Google аккаунта
3. Авторизуйтесь в своем Google аккаунте
4. Подтвердите доступ к Google Sheets
5. После авторизации будет создан файл `token.pickle` с токенами доступа

## Как это работает

- При первом запуске автоматически создается Google таблица с названием "Маршрутные карты"
- ID созданной таблицы сохраняется в файле `spreadsheet_id.txt`
- Все данные о созданных маршрутных картах сохраняются в эту таблицу
- При последующих запусках приложение использует уже созданную таблицу

## Структура таблицы

Таблица содержит следующие столбцы:
- id: Уникальный идентификатор записи
- Номер_бланка: Номер маршрутной карты
- Учетный_номер: (зарезервировано)
- Номер_кластера: (зарезервировано)
- Статус: (зарезервировано)
- Дата_создания: Дата и время создания маршрутной карты
- Путь_к_файлу: Путь к файлу маршрутной карты

## Преимущества использования Google Sheets

1. Данные доступны из любого места
2. Возможность совместной работы с другими пользователями
3. Автоматическое резервное копирование
4. Возможность просмотра и редактирования данных через веб-интерфейс Google Sheets
5. Интеграция с другими сервисами Google

## Возможные проблемы и их решения

### Проблема: "Ошибка аутентификации"
Решение:
1. Удалите файл `token.pickle`
2. Перезапустите приложение
3. Повторите процесс авторизации

### Проблема: "Таблица не создается"
Решение:
1. Проверьте, что файл `credentials.json` находится в корневой папке проекта
2. Убедитесь, что Google Sheets API включен в Google Cloud Console
3. Проверьте подключение к интернету

### Проблема: "Данные не сохраняются"
Решение:
1. Проверьте, что у аккаунта есть права на редактирование таблицы
2. Убедитесь, что таблица не открыта в другом приложении
