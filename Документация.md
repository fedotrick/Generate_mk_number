# Документация проекта "Генератор маршрутных карт"

## Описание проекта

Проект "Генератор маршрутных карт" предназначен для автоматизированного создания маршрутных карт в формате PowerPoint с интегрированными QR-кодами. Приложение позволяет генерировать как одиночные, так и множественные маршрутные карты с автоматической нумерацией и сохранением информации в Google Sheets.

## Основные компоненты

### 1. `streamlit_app.py`

Веб-интерфейс приложения на базе Streamlit. Предоставляет удобный графический интерфейс для создания маршрутных карт с современным дизайном.

#### Основные функции

- **Генерация одной маршрутной карты**: Позволяет создать одну маршрутную карту с указанным номером
- **Генерация нескольких маршрутных карт**: Позволяет создать несколько карт с последовательной нумерацией
- **Автоматическое предложение следующего номера**: Приложение автоматически предлагает следующий доступный номер маршрутной карты
- **Проверка дубликатов**: Автоматически проверяет, не существует ли уже карта с таким номером
- **Интеграция с Google Sheets**: Все созданные карты сохраняются в Google таблице
- **Современный интерфейс**: Улучшенный дизайн с градиентами, анимациями и адаптивной версткой

### 2. `google_sheets_utils.py`

Этот файл содержит основную логику приложения для работы с Google Sheets, включая функции для аутентификации, сохранения данных и проверки дубликатов.

#### Основные функции

- **`authenticate_google_sheets()`**: Аутентификация в Google Sheets API с использованием OAuth 2.0

- **`initialize_spreadsheet()`**: Инициализация таблицы Google Sheets. Если таблица не существует, создает новую.

- **`save_to_google_sheets(form_number, file_path)`**: Сохраняет информацию о созданной маршрутной карте в Google таблицу.

- **`check_duplicate_form_number(form_number)`**: Проверяет, существует ли уже маршрутная карта с данным номером в Google таблице.

- **`get_next_form_number()`**: Получает следующий доступный номер маршрутной карты из Google таблицы.

- **`generate_form_with_qr(template_path, output_path, form_number)`**: Генерирует одну маршрутную карту с QR-кодом на основе шаблона PowerPoint.

- **`generate_multiple_forms(template_path, start_number, count)`**: Генерирует несколько маршрутных карт с последовательной нумерацией.

## Использование

### Настройка Google Sheets

Перед первым запуском необходимо настроить доступ к Google Sheets API:
1. Следуйте инструкции в файле `ИНСТРУКЦИЯ_GOOGLE_SHEETS.md`
2. Поместите файл `credentials.json` в корневую папку проекта

### Веб-интерфейс

Для запуска веб-интерфейса дважды щелкните по файлу `запуск_streamlit.bat` или выполните команду:
```
streamlit run streamlit_app.py
```

При первом запуске будет открыта страница авторизации Google, где необходимо авторизовать доступ к Google Sheets.

## Файлы проекта

- `ШАБЛОН.pptx` - Шаблон PowerPoint для создания маршрутных карт
- `streamlit_app.py` - Основное приложение с веб-интерфейсом
- `google_sheets_utils.py` - Модуль для работы с Google Sheets
- `запуск_streamlit.bat` - Файл для быстрого запуска приложения
- `credentials.json` - Учетные данные для доступа к Google Sheets API (создается пользователем)
- `token.pickle` - Токены доступа к Google Sheets (создается автоматически)
- `spreadsheet_id.txt` - ID таблицы Google Sheets (создается автоматически)
- `ИНСТРУКЦИЯ_GOOGLE_SHEETS.md` - Инструкция по настройке Google Sheets
