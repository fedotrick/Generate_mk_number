# Документация проекта "Генератор маршрутных карт"

## Описание проекта

Проект "Генератор маршрутных карт" предназначен для автоматизированного создания маршрутных карт в формате PowerPoint с интегрированными QR-кодами. Приложение позволяет генерировать как одиночные, так и множественные маршрутные карты с автоматической нумерацией и сохранением информации в Excel файле.

## Основные компоненты

### 1. `streamlit_app.py`

Веб-интерфейс приложения на базе Streamlit. Предоставляет удобный графический интерфейс для создания маршрутных карт.

#### Основные функции

- **Генерация одной маршрутной карты**: Позволяет создать одну маршрутную карту с указанным номером
- **Генерация нескольких маршрутных карт**: Позволяет создать несколько карт с последовательной нумерацией
- **Проверка дубликатов**: Автоматически проверяет, не существует ли уже карта с таким номером
- **Интеграция с Excel**: Все созданные карты сохраняются в файл `маршрутные_карты.xlsx`

### 2. `generate_form_pptx_core.py`

Этот файл содержит основную логику приложения, включая функции для работы с Excel файлом, генерации QR-кодов и создания презентаций PowerPoint.

#### Основные функции

- **`create_database()`**: Создает Excel файл, если он не существует. Файл используется для хранения информации о созданных маршрутных картах.

- **`save_to_database(form_number, file_path)`**: Сохраняет информацию о созданной маршрутной карте в Excel файл. Использует openpyxl для безопасной работы с Excel.

- **`check_duplicate_form_number(form_number)`**: Проверяет, существует ли уже маршрутная карта с данным номером в Excel файле.

- **`generate_form_with_qr(template_path, output_path, form_number)`**: Генерирует одну маршрутную карту с QR-кодом на основе шаблона PowerPoint.

- **`generate_multiple_forms(template_path, start_number, count)`**: Генерирует несколько маршрутных карт с последовательной нумерацией.

## Использование

### Веб-интерфейс

Для запуска веб-интерфейса дважды щелкните по файлу `запуск_streamlit.bat` или выполните команду:
```
streamlit run streamlit_app.py
```

## Файлы проекта

- `ШАБЛОН.pptx` - Шаблон PowerPoint для создания маршрутных карт
- `маршрутные_карты.xlsx` - Excel файл для хранения информации о созданных картах
- `запуск_streamlit.bat` - Файл для быстрого запуска приложения
- `app.ico` - иконка приложения
