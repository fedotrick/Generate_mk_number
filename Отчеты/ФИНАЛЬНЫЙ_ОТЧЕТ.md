## Известные ограничения

### Проблемы с Kivy
- Установка Kivy может быть сложной на некоторых системах
- Графическая версия приложения требует установленного Kivy

### Проблемы с cx_Freeze
- Сборка исполняемого файла не работает с Python 3.13 из-за проблем совместимости cx_Freeze
- Рекомендуется использовать Python 3.11 или более раннюю версию для сборки

## Рекомендации по дальнейшему использованию

### Для пользователей без Kivy
Используйте консольную версию приложения:
```bash
python запуск_приложения.py
# или напрямую:
python generate_form_cli.py --help
```

### Для пользователей с Kivy
Можно использовать графическую версию:
```bash
python generate_form_pptx.py
```

### Для сборки исполняемого файла
1. Используйте Python 3.11 или более раннюю версию
2. Установите все зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сборку:
   ```bash
   python setup.py build
   ```
