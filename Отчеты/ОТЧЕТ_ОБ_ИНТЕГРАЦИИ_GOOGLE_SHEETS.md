# Отчет об интеграции Google Sheets в проект "Генератор маршрутных карт"

## Цель

Заменить использование локальных файлов Excel и SQLite на облачное хранилище Google Sheets для обеспечения централизованного хранения данных и возможности совместной работы.

## Выполненные работы

### 1. Анализ текущей архитектуры
- Проведен анализ файлов проекта
- Определены функции работы с локальным хранилищем
- Выявлены зависимости от Excel и SQLite

### 2. Подготовка инфраструктуры Google Sheets
- Добавлены необходимые зависимости в `requirements.txt`:
  - `google-api-python-client==2.70.0`
  - `google-auth==2.15.0`
  - `google-auth-oauthlib==0.8.0`
  - `google-auth-httplib2==0.1.0`

### 3. Создание модуля работы с Google Sheets
- Разработан файл `google_sheets_utils.py` со следующими функциями:
  - `authenticate_google_sheets()` - аутентификация через OAuth 2.0
  - `initialize_spreadsheet()` - инициализация таблицы
  - `save_to_google_sheets()` - сохранение данных
  - `check_duplicate_form_number()` - проверка дубликатов
  - `get_next_form_number()` - получение следующего номера

### 4. Модификация основного приложения
- Обновлен `streamlit_app.py` для использования Google Sheets вместо Excel
- Удалены функции работы с локальными файлами
- Добавлены импорты из нового модуля

### 5. Создание документации
- Подготовлена инструкция по настройке Google Sheets API (`ИНСТРУКЦИЯ_GOOGLE_SHEETS.md`)
- Обновлены `README.md` и `Документация.md`
- Создан пример файла учетных данных (`credentials.json.example`)
- Обновлен пакетный файл запуска с информацией о настройке

## Преимущества новой архитектуры

1. **Централизованное хранение данных** - все данные хранятся в облаке Google
2. **Возможность совместной работы** - несколько пользователей могут работать с одной таблицей
3. **Доступ из любого места** - данные доступны с любого устройства с интернетом
4. **Автоматическое резервное копирование** - Google обеспечивает надежное хранение данных
5. **Интеграция с другими сервисами** - возможность использовать данные в других приложениях Google

## Требования к использованию

1. Наличие аккаунта Google
2. Настройка Google Cloud проекта и API
3. Файл учетных данных `credentials.json` в корневой папке проекта

## Заключение

Интеграция Google Sheets в проект "Генератор маршрутных карт" позволяет перейти от локального хранения данных к облачному решению, что значительно улучшает возможности совместной работы и обеспечивает надежное хранение данных.
