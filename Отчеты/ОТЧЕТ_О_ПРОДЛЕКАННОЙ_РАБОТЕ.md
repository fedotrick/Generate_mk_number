## Текущая структура проекта

### Основные файлы:
- `generate_form_pptx.py` - основной файл приложения с графическим интерфейсом (требует Kivy)
- `generate_form_pptx_core.py` - ядро функциональности для работы с Excel и генерации карт
- `generate_form_cli.py` - консольная версия приложения (не требует Kivy)
- `demo_excel.py` - демонстрационный скрипт
- `test_core.py` - тесты основной функциональности
- `requirements.txt` - зависимости проекта
- `setup.py` - конфигурация для сборки исполняемого файла
- `README.md` и `Документация.md` - документация проекта
- `запуск_приложения.py` - скрипт для запуска приложения

### Вспомогательные файлы:
- `ШАБЛОН.pptx` - шаблон для генерации маршрутных карт
- `маршрутные_карты.xlsx` - Excel файл для хранения информации о созданных картах
- `app.ico` - иконка приложения

## Рекомендации
1. Для использования графической версии приложения необходимо установить Kivy:
   ```
   pip install kivy==2.2.1
   ```
2. Для сборки исполняемого файла рекомендуется использовать Python 3.11 или более раннюю версию
3. Либо обновить cx_Freeze до версии, совместимой с Python 3.13
4. Регулярно обновлять зависимости в файле requirements.txt

## Использование приложения

### Запуск приложения
```bash
python запуск_приложения.py
```

### Использование консольной версии напрямую
```bash
# Генерация одной маршрутной карты
python generate_form_cli.py --single --number 000001

# Генерация нескольких маршрутных карт
python generate_form_cli.py --multiple --start 100001 --count 10

# Помощь по параметрам
python generate_form_cli.py --help
```

### Использование графической версии (если установлен Kivy)
```bash
python generate_form_pptx.py
```
